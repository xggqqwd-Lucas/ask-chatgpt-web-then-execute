# Workflow examples

These examples are original prompts, not transcripts or reported experiments.

## Debug a signal-processing pipeline

```text
Use $ask-chatgpt-web-then-execute to discuss why a synthetic signal's FFT peak
might move after resampling. Share only a compact synthetic example.
Then inspect the local implementation, correct any demonstrated issue,
and verify the frequency estimate against the known synthetic input.
```

## Review a simulation plan

```text
Ask ChatGPT Web to critique a generic electrostatic model's proposed boundary
conditions and convergence checks. Then inspect the local model setup and
prepare a small preview. Distinguish solved quantities from display settings
and identify assumptions that need validation.
```

## Plan a literature search

```text
Use the skill to discuss search terms and screening criteria for a public
research topic. Then verify candidate sources using publisher pages and
available research tools. Separate the web assistant's suggestions from
facts confirmed in the original papers.
```

## Review and implement a code change

```text
Consult ChatGPT Web about tradeoffs in the proposed refactor using a minimal,
non-sensitive description. Evaluate the advice against the actual repository,
implement the justified change, and run relevant checks.
```

## Report the result

Include the consultation's main recommendation, the local evidence used to
accept or reject it, the changes made, the checks performed, and any remaining
uncertainty. A failed or incomplete web response is not a completed consultation.
